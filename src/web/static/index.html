LET'S GET YOU THERE

Three small steps. One big adventure.

Use this address on the laptop or your local network. Every player needs the same approved modpack.

01

Wake up your world

Go to Server and choose Start server. Wait until it says “Ready to explore.”

02

Open Minecraft Java

Use Minecraft 1.20.1, Forge 47.4.23, and the same mods as your server. Choose Multiplayer → Add Server.

03

Meet you inside

Give the server any name you like. Paste this into Server Address, then choose Done and Join Server.

Not on the list yet? Ask an admin to add your exact Minecraft username to the allowlist. A connection from another device needs the router’s public address and game port if port forwarding is configured.
